# Start Here

This vault is a creative commonplace book: a place to save things you find, follow curiosities, collect references, and connect them to your own ideas. It should stay easy to use. Add detail when it helps you; leave fields empty when it doesn’t.

## Where things go

- **00 Inbox** — quick captures you haven’t sorted yet. Keep capturing friction low; move things out when you have a moment.
- **01 Library** — things made or published by others: studios, people, websites, articles, tools, visual references, and other resources. All types live together.
- **02 Notes** — your own ideas, observations, concepts, research, and curated collections. The existing subject collections live here as small maps into the vault.
- **[[Tools|Hubs]]** — subject maps and directories that help you find related notes and resources.
- **03 Projects** — your creative work, experiments, and works in progress.
- **04 How To** — reusable instructions, workflows, and technical solutions.
- **templates** — starting points for new notes. Obsidian uses this folder; it’s for templates, not everyday notes.

A quick distinction: the Library holds a reference to something you found; Notes hold what you think or learn about it; Projects hold work you make; How To holds steps you may want to reuse.

## Capture and sort

Save a thought, link, or reference in **00 Inbox** first if that’s easiest. Later, decide what it is, move it to the right folder, add a useful type and subject tags, and link it to related notes. Then remove the processed capture from the Inbox. There are no required stages or checklists.

## Add a Library reference

Create a note in **01 Library** with a name you’ll recognise. In the command palette, choose **Templates: Insert template**, then select a starting point from `templates/`. Add the external link, set the `type`, and add a few subject tags if they help. Add `aesthetics` only when a visual style or mood is genuinely useful. A simple link note is enough.

The built-in Templates plugin is already enabled and its folder is set to `templates`. To change a template later, open that file in the `templates/` folder and edit it like any other Markdown note. Templates are optional; they don’t need to be applied to existing notes.

## Use metadata lightly

- **`type`** says what a Library item is: for example, `person`, `studio`, `website`, `publication`, `article`, `book`, `film`, `music`, or `tool`. Use one clear type per note. Individual people use `person`; represent their professional roles and disciplines with subject tags such as `designer` or `graphic-design` when relevant.
- **`tags`** describe what the note is about. Use lowercase kebab-case: `graphic-design`, `brand-identity`, `visual-communication`, `place-branding`, `creative-practice`, `internet-culture`, `art-direction`, or `ux-ui`. Use only the subjects that fit.
- **`aesthetics`** is optional. It can hold a style, era, genre, or mood such as `Bauhaus`, `Y2K`, `Playful`, or `Nostalgic`. Don’t use it just to fill a field.

These dimensions answer different questions: what it is, what it concerns, and what it looks or feels like. Don’t repeat the same information in all three.

## Connect notes

Use `[[Wikilinks]]` for outgoing links you choose because a relationship is useful: a studio to a concept it explores, a person to their work, or a project to its references. For example:

- A studio note can link to `[[Branding]]` and `[[Graphic Design]]`.
- A concept note can link to examples under **References** and to nearby ideas under **Related concepts**.
- A project can link to its research and inspiration.

Link meaningful relationships, not every matching word. You don’t need to create an empty note for every tag or add reciprocal links. Obsidian’s Backlinks core plugin is enabled, and **Backlinks in document** is already on. Obsidian automatically displays incoming links at the bottom of each note. Keep those generated backlinks separate from the outgoing links you curate in the note.

## Explore

Follow a wikilink to move between an idea and its examples, then use the incoming backlinks to see what else points there. The curated collections in **02 Notes** are also useful starting points. New topic maps can wait until there’s enough material to make one worthwhile.

## Keep it yours

A note can be a link, a sentence, a longer reflection, or nothing more than a question you want to follow. Templates are prompts, not forms. Add only the structure that makes the garden more enjoyable to tend.
